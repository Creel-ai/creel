## Codebase Patterns
- **Package:** src/taskrunner/ (being renamed to creel in PR #165, but use taskrunner for now on main)
- **Daemon API:** src/taskrunner/daemon/api.py — FastAPI app with /health, /v1/* endpoints
- **Daemon service:** src/taskrunner/daemon/service.py — bridges channels to ChatServer
- **ChatServer:** src/taskrunner/chat.py — handle_message(sender_id, text, ...) → LLM → tools → response
- **Channels:** src/taskrunner/channels/ — Telegram, iMessage, WhatsApp, each extends Channel base
- **Telegram:** src/taskrunner/channels/telegram.py + telegram_bridge.py — webhook + polling modes
- **Cron:** src/taskrunner/cron/ — manager.py, store.py (JSON persistence), executor.py, tool.py
- **Guardian:** src/taskrunner/guardian/ — core.py checks tool calls against policies
- **Sessions:** src/taskrunner/session.py — session persistence
- **Media:** src/taskrunner/services/ — media_store.py, transcription.py, vision.py (on ralph/media-messages branch)
- **Models:** src/taskrunner/models.py — AgentDefinition, AgentConfig, all channel configs
- **CLI:** src/taskrunner/cli.py — entry point, daemon start/stop/run
- **Tests:** tests/ — 108 test files, run with `uv run pytest tests/ -x -q`
- **CREEL_HOME:** defaults to ~/.creel/, overridable via env var
- **Daemon port:** configurable, check cli.py for default (likely 8099)
- **LLM calls:** src/taskrunner/llm.py — call_llm() uses anthropic Python SDK (NOT OpenAI)
- **LLM config:** Anthropic SDK reads ANTHROPIC_BASE_URL from env — THIS IS HOW WE POINT AT MOCK
- **LLM format:** Anthropic Messages API: POST /v1/messages, content blocks (text/tool_use), stop_reason, usage
- **Streaming:** client.messages.stream() with text_stream iterator, SSE events: message_start, content_block_start/delta/stop, message_delta, message_stop
