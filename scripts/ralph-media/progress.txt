## 2026-02-26 - MEDIA-004
- Implemented VisionProcessor class in src/taskrunner/services/vision.py
- Supports two LLM provider formats: Anthropic (type: image, source: base64) and OpenAI (type: image_url, data URI)
- Image resizing: uses Pillow to downscale images exceeding max_pixels (default 2048) while preserving aspect ratio
- Format conversion: unsupported formats (HEIC, HEIF, TIFF, BMP) converted to JPEG via Pillow
- RGBA-to-RGB conversion for JPEG compatibility (strips alpha channel)
- Graceful degradation: without Pillow, supported formats (PNG, JPEG, GIF, WEBP) are sent as raw bytes; conversion-needed formats return None with warning
- Configurable quality parameter for JPEG compression
- Added Pillow>=10.0.0 as optional dependency under [project.optional-dependencies] vision group
- Files changed: src/taskrunner/services/vision.py (new), tests/test_vision.py (new), pyproject.toml (vision optional dep)
- **Learnings:**
  - LLM uses Anthropic API exclusively (llm.py only imports anthropic) — but VisionProcessor supports both formats for future flexibility
  - Pillow is optional — the service works without it for natively-supported formats, only needed for resize/conversion
  - _detect_mime_type uses a hardcoded map for common types, falls back to mimetypes module
  - Test helpers (_make_png, _make_jpeg, _make_bmp) create real image files via Pillow for realistic testing
